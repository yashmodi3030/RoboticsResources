# Docker

## Recommended / New Resources

* [Docker ROS2 - OpenSplice](https://github.com/Adlink-ROS/docker-ros2-ospl-ce)
* [MicroROS Docker](https://github.com/micro-ROS/docker)

## Why Docker?

Docker is useful for robotics development because it allows you to:

* Maintain reproducible development environments.
* Avoid dependency conflicts.
* Run different ROS 2 environments without modifying the host system.
* Share complete robotics environments with other team members.
* Deploy robotics software consistently across machines.

# 🚀 GitHub Pages Deployment

The repository includes a web application showcasing these robotics resources with an interactive node canvas, real-time search, learning roadmap, and bookmarking.

## How to Enable GitHub Pages

### 1. Push this repository to GitHub

```bash
git add .
git commit -m "Update robotics resources"
git push origin main
```

### 2. Configure GitHub Pages in repository settings:
- Go to **Settings** -> **Pages**
- Source: **GitHub Actions** (or select *Deploy from a branch*, choose `main`, `/ (root)`)
- Click **Save**

### 3. Your website will be live at:
**`https://yashmodi3030.github.io/RoboticsResources/`**
